Ce este GitHub?

GitHub este o platformă online bazată pe Git, un sistem de control al versiunilor. Le permite dezvoltatorilor să gestioneze codul, să urmărească modificările și să lucreze împreună.

📦

Repository-uri

Un repository este un spațiu în care sunt organizate fișierele, codul sursă și istoricul unui proiect.

⌨️

Controlul versiunilor

Git păstrează istoricul modificărilor, astfel încât poți vedea ce s-a schimbat și când.

🤝

Colaborare

Mai mulți dezvoltatori pot contribui la același proiect, pot discuta schimbări și pot revizui codul.
